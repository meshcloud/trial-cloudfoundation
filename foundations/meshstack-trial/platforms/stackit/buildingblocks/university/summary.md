# 🎓 STACKIT University

Head to [STACKIT University](https://university.stackit.cloud) and register to view the course catalog and start
your learning journey. Use a STACKIT Sandbox project to run the hands-on exercises in the courses.

> **All STACKIT University services are free of charge.**

## What you can do there

| Format | What it is |
|---|---|
| **E-Learning** | Self-paced courses built by STACKIT experts — start any time, pick up where you left off. |
| **Webinars** | Live sessions with STACKIT experts, plus an on-demand archive. |
| **Workshops** | Hands-on practical exercises, remote or on-site. |
| **Seminars** | In-depth technical deep dives on individual services. |

Finish a program and you get an individual **digital certificate** you can share.

## Suggested first steps

1. Sign in at [university.stackit.cloud](https://university.stackit.cloud) with your STACKIT account.
2. Start with the **Cloud Engineer** program if you are new to the platform.
3. Apply what you learn in the STACKIT sandbox project that came with this workspace.
