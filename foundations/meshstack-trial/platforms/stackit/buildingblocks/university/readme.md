STACKIT University is STACKIT's free learning platform: e-learning courses, live webinars,
hands-on workshops and technical seminars, all built by STACKIT experts. 

## 🎯 When to use it

Go to STACKIT University when you already have a STACKIT sandbox project and you:
- Are new to STACKIT and want a guided path into compute, storage, networking and automation.
- Want your whole team to find the training material where they already work.
- Are working toward a Cloud Engineer or *Certified STACKIT Partner* certificate.

## 💡 Usage examples

**Example 1: Onboarding a new team**
A team receives their first STACKIT sandbox project and orders this alongside it, so every
member lands on the Cloud Engineer learning program on day one.

**Example 2: Preparing for a certification**
An engineer heading for the STACKIT Partner certificate opens the building block in meshPanel and
follows the link straight into the program, signing in with their existing STACKIT account via SSO.
